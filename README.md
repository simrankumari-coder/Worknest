# Smart Co-Working Space Management

A frontend web application for discovering, exploring, and booking co-working spaces.

The platform allows users to search for suitable workspaces, view workspace details, make bookings, manage their bookings, and interact with workspace owners.

## 🚀 Features

### 👤 User Features
- User registration and login
- User profile
- Workspace preferences
- Search workspaces
- Filter workspaces by:
  - Location
  - Price
  - Workspace type
- Check workspace availability
- View workspace details
- Book a workspace
- View My Bookings
- Send inquiries to workspace owners
- User notifications
- Logout

### 🏢 Space Owner Features
- Space Owner registration
- Space Owner profile
- Space Owner Dashboard
- View workspace information
- Space Owner notifications

## 🛠️ Tech Stack

## 🔐 Role-Based Features

The application supports two roles:

User:
Users can search and book co-working spaces, manage their bookings, and receive notifications.

Space Owner:
Space owners can access their dashboard and owner-specific notifications.

// Admin functionality is not included in the current frontend version.

## 💾 Data Storage

* This project is currently frontend-focused.
* Workspace data is provided through mock/local data.
* Booking information is stored using localStorage.
* User registration/login is implemented as a frontend demonstration.
* Contact form uses a mock JSON Server API during local development.

## ⚙️ Installation

Clone the repository:

git clone https://github.com/simrankumari-coder/Worknest

Go to the project folder:

cd smart-coworking

Install dependencies:

npm install

Start the development server:

npm run dev

The application will run locally using the Vite development server.

## 📦 Build for Production
npm run build

To preview the production build:

npm run preview
